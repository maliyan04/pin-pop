Game About

About PIN POP

A lightweight casual puzzle game. Pop connected pins, clear the board, and finish before your taps run out.

How to Play

  1. Look at the pin arrangement.
  2. Select the correct pin.
  3. Trigger chain reactions.
  4. Clear the board using the available taps.
  5. Complete the level and unlock the next challenge.

Goal

Clear the required pins using as few taps as possible.

"Think carefully. Tap smart. Make the biggest POP!"
